## 🎂 Overview

**La Claire Pâtisserie** is a high-end digital storefront built for a boutique French confectionery brand. It bridges culinary craftsmanship with an elevated digital shopping experience:

- **Bespoke Hamper Builder:** Step-by-step interactive gift box configurator letting customers choose box style, pastries, ribbons, and custom greeting notes with live price estimation.
- **Brand Storytelling:** High-fidelity video banners, artisanal ingredient showcases, and customer testimonial carousels.
- **Frictionless WhatsApp Routing:** Automatically compiles custom hamper orders into pre-filled WhatsApp messages for instant customer-to-artisan communication.

---

## 🛠️ Tech Stack & Highlights

- **Framework:** Next.js 15 (App Router, dynamic metadata)
- **UI & Motion:** React 19, Framer Motion 12, GSAP ScrollTrigger animations
- **Styling:** Tailwind CSS with warm luxury brand palette (cream, gold, espresso)
- **Icons:** Lucide React
- **Deployment:** Vercel Edge Network

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/krrishvimal/la-claire-.git
cd la-claire-

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your browser.
